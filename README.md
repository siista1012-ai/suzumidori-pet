# すずみどり

`すずみどり` は、明るい気持ちになれるけれど画面の端にずっといても疲れない、小さな守り鳥のCodex petです。

## コンセプト

- まるいしずく型の小鳥
- セージミントの体、白いお腹、セージグレーの羽
- 小さなクリーム色のくちばし
- 作業中に急かさず、そっと整えてくれる雰囲気

## ファイル

- `pet.json`: Codex petの設定
- `spritesheet.webp`: Codex pet用スプライトシート
- `qa/contact-sheet.png`: 全ポーズの確認用一覧
- `qa/previews/*.gif`: 各状態のアニメーション確認用GIF
- `qa/validation-summary.json`: 検証結果の要約

## 検証

- スプライトシートサイズ: `1536x1872`
- セルサイズ: `192x208`
- 状態数: 9
- 透明化エラー: なし
- 最終目視QA: pass

## Codexで使うファイル

Codexのペットとして使う場合は、`pet.json` と `spritesheet.webp` を同じフォルダに置きます。

## 別ペット

- `pets/ki-suzume`: 丸い黄色いすずめフォルムの `黄すずめ`
- `pets/ruri-usagi`: 淡い青いウサギフォルムの `ルリウサギ`
  - `motions/`: 右ジャンプ、左ジャンプ、にんじん待機の9枚フル版
  - Codex本体には、固定仕様に合わせて右左ジャンプ8枚、にんじん待機6枚を反映
