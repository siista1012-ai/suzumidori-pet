# 黄すずめ

`黄すずめ` は、添付画像のような丸くて低いフォルムの黄色い小鳥をもとにしたCodex petです。

## コンセプト

- 低く丸い、横幅のあるふわふわヒナ雀
- やわらかい黄色の頭と体、白いお腹、薄いベージュの大きめの羽
- 短い扇形の尾、黒い丸目、ピンクのほっぺ
- すずみどりの色違いではなく、別フォルムの小鳥

## ファイル

- `pet.json`: Codex petの設定
- `spritesheet.webp`: Codex pet用スプライトシート
- `figma/kisuzume-atlas.png`: Figma向けの透過PNG版
- `figma/cells/*.png`: Figmaで扱いやすいセル単位の透過PNG
- `qa/contact-sheet.png`: 全ポーズの確認用一覧
- `qa/transparency-check.png`: 黒・白・市松背景での透過確認
- `qa/previews/*.gif`: 各状態のアニメーション確認用GIF

## 検証

- スプライトシートサイズ: `1536x1872`
- セルサイズ: `192x208`
- 状態数: 9
- 透明ピクセルRGB残り: なし
- Figma向けPNG: あり
